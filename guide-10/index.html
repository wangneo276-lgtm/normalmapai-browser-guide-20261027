Understanding Normal Maps, Grayscale Height, and Mesh Displacement

Creating realistic materials for 3D environments, architectural visualization, and games requires accurate surface maps. Transforming a flat photograph into a usable material involves distinct map types that convey how light interacts with surface geometry. NormalMapAI is a free browser tool that turns a photo into a normal map and shows a live 3D preview directly on screen. Unlike legacy desktop workflows that relied on discontinued Photoshop 3D filters, Materialize, or CrazyBump, this tool requires no install, no license key, and no project setup. It also avoids the limitations of basic one-off converters that only output a simple purple normal image without companion channels.

To construct materials accurately, artists must recognize the structural differences between surface calculation techniques:

  • Normal Maps: A normal map encodes XYZ surface slopes directly into RGB color channels. By storing directional angles across red (X), green (Y), and blue (Z) values, game engines and 3D renderers simulate complex lighting without extra geometric triangles.
  • Bump and Height Maps: A bump or height map represents elevation purely through grayscale luminance, where light pixels denote height and dark pixels denote depth.
  • Displacement Maps: A displacement map actively moves vertices of a 3D mesh. Because displacement alters physical geometry, it changes the outer silhouette of an object.

Engine Export Presets and the OpenGL Versus DirectX Distinction

Normal maps store green channel data to indicate whether vertical lighting tilts upward or downward. The tool categorizes these into two major industry standards:

  • OpenGL (+Y / Y+): The green channel encodes upward-facing surface normals. This standard is required by Blender, Godot 4, and Unity (URP and Built-in).
  • DirectX (−Y / Y−): The green channel inverts vertical vectors downward. This standard is required by Unreal Engine and Unreal Engine 5.

When exporting from the Free Normal Map Generator Online, users can select tailored engine export presets: Unity (URP / Built-in), Unreal Engine, Godot 4, Blender, and All maps (generic / three.js). Available export sizes are 512, 1024, 2048, and 4096 px, bundled in a ZIP named for the chosen engine.

The export presets pack channels the way each engine expects:

  • ORM Packing: Combines Ambient Occlusion, Roughness, and Metallic into RGB channels for Unreal Engine.
  • MetallicSmoothness Packing: Formats maps for Unity, with R = Metallic and A = Smoothness (1 − roughness).
  • 16-Bit Grayscale: Height and displacement export as 16-bit PNG files to avoid stepping artifacts.

These export presets support indie game props from phone photos of concrete, brick, or metal for Unity or Unreal prototypes; archviz floors and walls from wood, tile, and plaster; cutout decals; and Blender look-dev with a Principled BSDF set (base color, normal, roughness, metallic).

Connecting Exported Maps in Blender's Principled BSDF

Hooking up your generated textures in Blender follows the FAQ instructions:

  1. Export an OpenGL (Y+) PNG normal map or download the Blender ZIP.
  2. In Blender's Shader Editor, add an Image Texture node and open your normal map.
  3. Set the Color Space on the Image Texture node to Non-Color.
  4. Add a Normal Map node set to Tangent Space, and connect the Color output of the Image Texture node to the Color input of the Normal Map node.
  5. Connect the Normal output of the Normal Map node into the Normal input of the Principled BSDF node.
  6. Connect companion maps: link Base Color to Base Color, Roughness to Roughness (Non-Color), and Metallic to Metallic (Non-Color).

Frequently Asked Questions

Which normal map format should I choose for Unity, Unreal Engine, Godot, and Blender?

Blender, Unity (URP and Built-in), and Godot 4 use OpenGL (Y+) normal maps. Unreal Engine and Unreal Engine 5 require DirectX (Y-) normal maps. The export presets match that green channel orientation, including DirectX versus OpenGL.

Are photos uploaded to an external server?

No. Photos never leave the device and are not uploaded. All processing takes place locally in your browser using WebGL2 or CPU and Canvas.

How are height and displacement maps exported?

Height and displacement export as 16-bit PNG files, so displacement survives compression better than 8-bit gray maps. The same 16-bit height can be used for surface relief or 3D-print style height workflows.

What is the channel layout for Unity MetallicSmoothness?

In the MetallicSmoothness map in the engine ZIP, the Red channel stores Metallic (R = Metallic), and the Alpha channel stores Smoothness (A = Smoothness, calculated as 1 − roughness).
